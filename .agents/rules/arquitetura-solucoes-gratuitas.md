# Regra: Prioridade Máxima para Soluções Gratuitas

Ao sugerir integrações, ferramentas, bancos de dados ou serviços de infraestrutura (ex: APIs de WhatsApp, provedores de email, plataformas de deploy, ferramentas de IA):

1. **Sempre priorize a alternativa 100% gratuita ou Open Source** que possa ser rodada localmente ou em tiers gratuitos permanentes (ex: Docker local, SQLite em vez de Postgres gerenciado, Evolution API em vez de Z-API, Nginx, etc).
2. O esforço técnico (instalar Docker, configurar servidores) **não** deve ser motivo para desencorajar a via gratuita. Presuma que o usuário prefere o trabalho manual de setup em vez de contrair custos mensais.
3. Não sugira Trials (períodos de teste grátis) de ferramentas pagas como primeira opção.
4. Se mencionar soluções pagas/SaaS para contexto, coloque-as sempre em segundo plano e deixe claro que a via oficial e recomendada do projeto é a rota gratuita (Self-Hosted/FOSS).
